# Greenrun Ubuntu Images

The runner images are intentionally smaller than GitHub-hosted virtual
machines. They provide the runtimes needed to bootstrap JavaScript and
container actions; workflows should continue to use official `setup-*` actions
for project toolchains.

Published labels:

- `ghcr.io/kiwi-init/greenrun-ubuntu:22.04-latest`
- `ghcr.io/kiwi-init/greenrun-ubuntu:24.04-latest`

Every weekly build also receives an immutable date tag.
